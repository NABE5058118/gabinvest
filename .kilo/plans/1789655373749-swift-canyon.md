# План работы по проекту Gab Invest

## Краткий обзор проекта
Telegram Mini App маркетплейс коммерческой недвижимости для gab-invest.ru. Stack: React 18 + TS + Vite, Express + Prisma 6, aiogram 3.x, PostgreSQL 17, Docker, nginx.

**Локально:** Backend 15/15 тестов ✅, Frontend 5/5 тестов ✅, TypeScript без ошибок ✅.

**Проблемы на продакшене (Selectel, Ubuntu 24.04):**
- Backend падал с ошибкой модуля `/app/dist/routes/objects` → **исправлено** через `tsconfig.json`: `module: NodeNext`, `moduleResolution: NodeNext`.
- Frontend падал с `host not found in upstream "backend"` → **исправлено** через фоллбэк `VITE_API_URL: ''` в `frontend/src/utils/api.ts` (относительные пути, nginx проксирует).
- Бот падал с таймаутом к Telegram API → **исправлено**: добавлен `aiohttp-socks`, настроен `PROXY_URL` через `AiohttpSession`.

## Текущие артефакты
- **Backend:** `/backend` — Express, Prisma, Zod, multer, JWT, rate-limit, helmet, cors.
- **Frontend:** `/frontend` — React 18, Vite, React Router, Axios, AuthContext, FavoritesContext.
- **Bot:** `/bot` — aiogram 3.x, polling, web_app кнопка.
- **Nginx:** `/nginx/nginx.conf` — reverse proxy, SSL терминация, `/api/` и `/uploads/` на backend.
- **Prisma schema:** `User`, `Object`, `Favorite`, `Lead`, `CommercialOffer`, `Consent`.
- **Docker:** `docker-compose.prod.yml` — postgres, backend, frontend, bot, certbot.
- **Админка:** CRUD объектов, загрузка КП (PDF/PPTX), загрузка/удаление фото, админ-логин.

## Примечания
- Все изменения уже закоммичены в `main`.
- Dockerfile backend использует `node:22-slim` (multi-stage build).
- Dockerfile frontend использует `nginx:alpine` (multi-stage build).
- Бот зависит от backend и требует `PROXY_URL` для работы из РФ.
- `docker-compose.prod.yml` использует отдельные сети `frontend-net` и `backend-net`.
- Загрузки хранятся в томе `backend-uploads` (Docker volume).
